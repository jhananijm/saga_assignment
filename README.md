# Saga Technical Assignment (Azure Architecture + GitHub Actions + Observability)

This repository contains three parts of the Saga technical assignment:

## Assignment 1: Azure Multi-Tenant AI Platform Architecture
📌 Folder: `part-1-cloud-architecture-design/`

Includes:
- Architecture diagram
- Multi-tenant isolation strategy
- Environment separation (Dev/Test/Prod)
- Failure modes + degradation strategies
- Rationale for Azure service choices

## Assignment 2: GitHub Actions CI/CD Strategy
📌 Folder: `part-2-cicd-deployment/`

Includes:
- CI/CD deployment strategy
- Zero downtime deployment approach
- Rollback strategy
- Secrets handling using OIDC + Key Vault
- Infrastructure vs application pipeline separation
- Example workflow YAML templates

## Assignment 3: Reliability & Observability
📌 Folder: `part-3-reliability-observability/`

Includes:
- Metrics, logs, and alerting strategy
- Example production alerts
- Realistic incident scenario and response flow
- Monitoring approach using Azure Monitor, Application Insights, and Log Analytics
